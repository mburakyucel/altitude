Lumen command line

Every command reads files or standard input and writes to standard output. Nothing on disk changes.

Commands

CommandWhat it doesFlags
lumen tail FILEFollow a file as a timeline--since
lumen grep PATTERNMatching lines with context--context
lumen export FILEOne standalone HTML file--out

Examples

# errors from the last hour
lumen grep --level error --since 1h app.log

# a timeline for a bug report
lumen export app.log --out timeline.html

Exit codes

  • 0 the command finished
  • 1 nothing matched
  • 2 a file could not be read
