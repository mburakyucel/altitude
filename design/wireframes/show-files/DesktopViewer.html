Lumen command line

Every command reads files or standard input and writes to standard output. Nothing on disk changes.

Commands

CommandWhat it doesCommon flags
lumen tail FILEFollow a file and print new lines as a timeline--since, --level
lumen grep PATTERN FILEShow matching lines with the lines around them--context, --ignore-case
lumen export FILEWrite a timeline to one standalone HTML file--out, --title

Examples

Errors from the last hour, then a timeline to attach to a bug report:

# errors from the last hour, three lines of context
lumen grep --level error --since 1h --context 3 app.log

# a timeline for a bug report
lumen export app.log --since 30m --out timeline.html

Exit codes

  • 0 the command finished
  • 1 nothing matched
  • 2 a file could not be read

Environment

Every flag has an environment variable; the table is in README.md. Report anything unclear on the issue tracker.

Tip: lumen tail - reads standard input, so it works at the end of any pipe.
