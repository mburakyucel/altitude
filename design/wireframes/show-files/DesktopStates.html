# Lumen command line

Every command reads files or standard input and writes to standard output. Nothing on disk changes.

## Commands

| Command | What it does | Common flags |
| --- | --- | --- |
| `lumen tail FILE` | Follow a file and print new lines as a timeline | `--since`, `--level` |
| `lumen grep PATTERN FILE` | Show matching lines with the lines around them | `--context`, `--ignore-case` |
| `lumen export FILE` | Write a timeline to one standalone HTML file | `--out`, `--title` |

## Examples

Errors from the last hour, then a timeline to attach to a bug report:

```sh
# errors from the last hour, three lines of context
lumen grep --level error --since 1h --context 3 app.log

# a timeline for a bug report
lumen export app.log --since 30m --out timeline.html
```

## Exit codes

- `0` the command finished
- `1` nothing matched
- `2` a file could not be read

Lumen

Full size ↗

CI   License: MIT   Release 0.9

Lumen turns noisy logs into a timeline you can read. It runs wherever Python 3.10 does and keeps no state of its own.

Install · Two-minute tour · Configuration

Two-minute tour

Follow a file, then narrow it to what broke:

# the last ten minutes, then new lines
lumen tail app.log --since 10m

# every timeout, with context
lumen grep timeout --context 3

Install

  • pipx install lumen-logs (recommended)
  • brew install lumen on macOS
  • From source: see CONTRIBUTING.md

Status

  • Tail and follow files
  • Search with context
  • Export a timeline to HTML
  • Windows support

Configuration

Settings come from lumen.toml, then the environment:

KeyDefaultEnvironmentWhat it sets
colorautoLUMEN_COLORColour output: auto, always or never
since1hLUMEN_SINCEHow far back tail starts reading
time_formatisoLUMEN_TIME_FORMATTimestamp style at the start of each line

Note: Lumen only reads files. It never moves, truncates or rotates them.
